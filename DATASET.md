# DATASET

## Description

The dataset contains Chinese land-use and territorial spatial planning texts organized for binary land-use conflict identification. Each row corresponds to one released text sample and includes the original filename, title, text content, source field, source category, binary label, and word count.

## Files

- `data/unified_land_use_dataset.csv`: unified tabular dataset.
- `splits/heldout_split_ids.csv`: sample IDs for the held-out evaluation split.
- `splits/repeated_stratified_kfold_ids.csv`: sample IDs for repeated stratified K-fold assessment.

## Columns

- `sample_id`: stable sample identifier generated from category, label, and within-category order.
- `filename`: original released text filename.
- `title`: document title.
- `content`: text content.
- `source`: source description retained from the released dataset.
- `category`: source category, including `plan_texts`, `policy_files`, and `conflict_cases`.
- `label`: binary class label; `0` denotes non-conflict and `1` denotes conflict.
- `word_count`: text-length field retained from the released dataset.

## Split generation

The held-out split and cross-validation fold IDs are generated by stratifying on the binary label. The held-out split uses random seed `42` and a test fraction of `0.2`. The cross-validation file uses repeated stratified 5-fold assignment with 3 repeats and seeds `42` to `44`.

## Data-use note

The files retain the released manuscript data fields and do not alter sample text, labels, or tabulated values. Users should cite the GitHub repository and the manuscript when reusing the data.
